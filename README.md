# Reverb (reverb)

Reverb is a marketplace for musicians to buy and sell new, used, and vintage musical instruments and gear, owned by Etsy. The Reverb API is a HATEOAS hypermedia REST API using application/hal+json, with interactive Swagger documentation and an X-Auth-Token header authentication scheme.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/reverb/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/reverb/refs/heads/main/apis.yml)

## APIs

### Reverb REST API

HATEOAS hypermedia REST API at https://reverb.com/api using application/hal+json. Auth via POST /api/auth/tokens to obtain a token used in X-Auth-Token header. Endpoints exposed via _links include accounts, articles, listings, autocomplete, autosuggest, cart, categories, collections, currencies, payment_methods, price_guides, my account, my orders, my listings, etc.

- **Human URL:** [https://reverb.com/page/api](https://reverb.com/page/api)
- **Base URL:** `https://reverb.com/api`
